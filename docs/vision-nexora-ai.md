# Nexora AI : la vision (dite par le fondateur, 29/10/2026)

**Nexora AI est le portail de l'accès ultime à l'IA.** On reprend beaucoup d'outils, de cadres et de projets libres (GitHub, GitLab), on les adapte, on les rebrande entièrement « Nexora » et on les rend faciles pour le client. On vend aussi l'installation d'une infrastructure IA, physique ou virtuelle ; le site montrera un DGX Spark, un DGX Station ou un grand grappe de serveurs en image, éventuellement animée.

| Produit | Rôle |
|---|---|
| **Nexora AI** (portail et espace client) | Accès à l'IA à son plein potentiel. Compte, portefeuille avec recharge, clés d'API, tableau de bord façon OpenRouter, choix des modèles depuis le compte. |
| **Modèles et API** | Passerelle unique : modèles tiers (via les fournisseurs du fondateur), puis forfaits de modèles auto-hébergés et modèles Nexora. Facturé au jeton. |
| **Nexora WorkStudio** | Abonnement mensuel, trimestriel ou annuel, géré depuis le site, pensé pour que le client fasse lui-même ; gabarits préconfigurés, Nexora Connect, paliers à définir. Branché d'emblée sur un modèle ; jetons facturés au client. |
| **OPSYS-AI** | Le produit phare : automatisation totale, configurée par nos techniciens, installée sur une infrastructure physique chez le client (100 % souverain) ou sur une infrastructure virtuelle qui lui appartient. |
| **Nexora WebPilot** | Notre propre API de type Firecrawl (recherche, extraction, exploration) et Browser Use (navigation, actions), vendue comme OpenRouter vend les modèles. |
| **Nexora Privacy Router** | Couche de protection commune, incluse par défaut (jamais payante) : contrôle des données qui sortent, politiques par client. |
| **Agent de code Nexora** | Gratuit : téléchargeable ou utilisable depuis le panneau du client. |
| **Espace cloud** | Avec abonnement, avec un GitLab ou Nexora Gitspace / Forgejo intégré au panneau. |
| **RAG** | Avec abonnement, connectable à l'agent de code, à OPSYS-AI ou à l'infrastructure du client. |
| **VPS** | Installation en un clic des meilleurs outils IA (Hermes Agents, OpenClaw…), puis nos propres outils. |
| **Nexora Creative** (plus tard) | Outils connectés à des modèles image, son et vidéo pour créer du marketing : un « Adobe IA ». |
| **Outils gratuits** | Utilisent nos modèles et nos serveurs. |
