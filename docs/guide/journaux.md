# Les journaux

Chaque exécution de workflow est enregistrée dans **Journaux** : déclencheur, durée, statut, coût en jetons, et le détail de chaque bloc (entrées, sortie, erreurs).

- Filtrez par workflow, statut, date ou déclencheur.
- Ouvrez une exécution pour voir son **arbre d'exécution** bloc par bloc ; un bloc en échec affiche son message d'erreur.
- **Relancer** rejoue une exécution échouée.

La consommation de modèles de toute l'instance est dans **Réglages › Consommation** (administrateurs de l'organisation).
