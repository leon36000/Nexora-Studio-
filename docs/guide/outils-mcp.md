# Outils MCP

Le **Model Context Protocol** (MCP) permet à un agent d'utiliser des outils externes.

- **Nexora Connect** est déjà branché dans chaque espace : ses outils donnent accès à plus de 1 600 services.
- **Ajouter un serveur MCP** : Réglages › Outils MCP › Ajouter, puis l'adresse du serveur et, si besoin, son jeton.
- **Exposer vos workflows en MCP** : un workflow déployé comme outil MCP devient utilisable par d'autres assistants (Claude, Cursor…) qui se connectent à votre instance.
