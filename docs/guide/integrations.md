# Intégrations et outils

Nexora se branche sur vos outils de deux façons, utilisables ensemble.

## Nexora Connect

Plus de 1 600 services (Google, Microsoft 365, Brevo, Slack, HubSpot, Pennylane…) exposés comme **outils MCP**, déjà branchés dans chaque espace (**Réglages › Outils MCP**). Un bloc Agent peut les utiliser directement : ajoutez « Nexora Connect » dans ses outils et décrivez la tâche.

## Blocs d'intégration

La barre d'outils propose aussi des **blocs dédiés** par service (Gmail, Slack, Notion…). Chacun demande un compte connecté :
- **OAuth** (bouton « Connecter ») : l'administrateur doit avoir déclaré l'application OAuth du service sur l'instance ;
- **clé d'API** : collez la clé du service dans le bloc ou dans les **secrets** de l'espace.

Les identifiants sont chiffrés et restent sur votre instance.

## Recherche web

Le bloc **Recherche web** apparaît quand l'administrateur a activé la recherche (question de l'installateur). Les requêtes partent alors vers des moteurs de recherche publics.
