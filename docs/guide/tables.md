# Les tables

Une **table** stocke des données structurées (contacts, devis, tickets…) directement dans Nexora, sans tableur externe.

- **Tables › Nouvelle table**, puis ajoutez des colonnes typées (texte, nombre, date, case à cocher…).
- Importez un fichier CSV ou remplissez-la depuis un workflow (bloc **Table** : ajouter, modifier, rechercher des lignes).
- Une table peut servir de liste de travail : un workflow planifié lit les lignes « à traiter » et met à jour leur statut.
