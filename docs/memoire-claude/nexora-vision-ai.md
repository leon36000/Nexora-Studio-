Nexora AI = le portail de l'accès ultime à l'IA (outils libres adaptés et rebrandés Nexora). Produits : portail et espace client (portefeuille, clés, tableau de bord façon OpenRouter), Modèles et API, WorkStudio (abonnement mensuel/trimestriel/annuel, gabarits, Connect, paliers à définir par le fondateur, branché d'emblée sur un modèle, jetons facturés), OPSYS-AI (phare, installé par techniciens, souverain), WebPilot (API Firecrawl + Browser Use vendue comme OpenRouter), Privacy Router (inclus, jamais payant), agent de code gratuit, espace cloud avec GitLab/Gitspace/Forgejo, RAG par abonnement, VPS en un clic (Hermes Agents, OpenClaw), Creative (plus tard), outils gratuits, vente d'infrastructure IA (DGX).

Texte complet : `docs/vision-nexora-ai.md` du dépôt nexora-workstudio (GitLab). **Why:** éviter de perdre le fil. **How to apply:** terminer d'abord portefeuille, tableau de bord, WorkStudio branché sur un modèle (clé auto à la commande), WebPilot ; réponses COURTES (le fondateur s'est plaint du bavardage). Voir [[nexora-organisation-gitlab]] et [[nexora-webpilot-privacy-router]].

**Ajout 29/10 (soir)** : Nexora Bot (gratuit, branché sur nos modèles, code ouvert prévu : fondateur y travaille) et plugins WordPress Nexora (plugin gratuit et ouvert, automatisation du site — SEO, articles de blogue — par abonnement : « un WorkStudio du site web »). Ils vont dans la page Nexora Apps (petite place, pas dans la barre principale). Le fondateur veut une licence ouverte et gratuite avec indemnités en usage commercial : **à clarifier** (« libre » au sens strict ne permet pas d'exiger une redevance ; un plugin distribué par WordPress.org doit être sous GPL ; options : plugin GPL + service payant, ou licence à code source disponible avec usage commercial payant). Défaut WorkStudio : modèle GLM 5.3 Flash, 5 M de jetons inclus en crédits.
