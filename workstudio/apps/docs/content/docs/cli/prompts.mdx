Manage prompts

These commands accept the [global options](/cli/commands#global-options).

## List prompts

```bash
sim prompts list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Case-insensitive substring match against the prompt name. |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "name". Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "asc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
| `--cursor <value>` | No | Continue from nextCursor returned by a previous result. |

</CommandTable>

API request and response schemas: [listPrompts](/api-reference/prompts/listPrompts).

## Get prompt

```bash
sim prompts get <promptId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `promptId` | Yes | Prompt identifier, or its name. |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--label <value>` | No | Return the version this label points at. Defaults to `production`. Accepted values: `production`, `test`. |
| `--to-version <value>` | No | Return this version number instead of a labelled one. |

</CommandTable>

API request and response schemas: [getPrompt](/api-reference/prompts/getPrompt).

## Create prompt

```bash
sim prompts create [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--name <value>` | Yes | Name, unique within the workspace regardless of case. |
| `--description <value>` | No | What the prompt is for. Defaults to "". |
| `--content <value>` | Yes | Text of version 1, with `{{variables}}`. |
| `--variables <json\|@file>` | No | Declarations of the variables. A placeholder without one is a `text` variable; a declaration without a placeholder is dropped. Defaults to []. (JSON, or @path / @- to read a file or stdin). |
| `--note <value>` | No | Note of version 1. Defaults to "". |

</CommandTable>

API request and response schemas: [createPrompt](/api-reference/prompts/createPrompt).

## Create prompt version

```bash
sim prompts versions create <promptId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `promptId` | Yes | Prompt identifier, or its name. |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--content <value>` | Yes | Text of the new version, with `{{variables}}`. |
| `--variables <json\|@file>` | No | Declarations of the variables. A placeholder without one is a `text` variable; a declaration without a placeholder is dropped. Defaults to []. (JSON, or @path / @- to read a file or stdin). |
| `--note <value>` | No | What changed in this version. Defaults to "". |

</CommandTable>

API request and response schemas: [createPromptVersion](/api-reference/prompts/createPromptVersion).
